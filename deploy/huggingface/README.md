Veritas finds the dependency upgrades that break a repository, proves it with the project's own tests, and writes a fix that the tests then check.

This Space is a public demo. It runs on the sample repositories from the benchmark only, because there is no container sandbox here to isolate code from other repositories.

Source: https://github.com/Milliebanned/Veritas
